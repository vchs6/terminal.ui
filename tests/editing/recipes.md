# Deferred public integration recipes

The committed Cangjie executable is the normal public consumer. Run it only after the production source actually exports `TextInput`, `TextArea`, `TextSelection`, `TextEditLimits`, `TextEditIssue`, `TextEditController`, `TextEditSnapshot`, `KeyboardDecoder`/extended `KeyEvent`, Theme/Canvas/viewport/default action, and `Application.copyLocalText` with `SessionResult`. The manifest uses only `cjtui = { path = "../.." }`; attach it by merging this `tests/editing/` directory into the fixed product checkout or by changing **only** the path dependency for a clean copy. Do not copy product source into this fixture.

1. **True editing RED:** first build the pinned prerequisite product and its own tests; then `bash tests/editing/run.sh`. Count only unresolved editor symbols as TASK118 RED. A missing SessionResult, `copyLocalText`, Canvas/Theme, focus, viewport, `KeyEvent` modifiers, or a syntax/setup error blocks admission.
2. **Controller lifecycle:** mount `TextInput(value, controller: Some(c))` and assert zero revisions/selection/history; bind the same `c` to a second active input and expect `AlreadyMounted`; unmount and assert `isValid=false`, mutations `StaleReference`; remount and assert zero local state and old guard rejection even if visible text/revisions match.
3. **Reentrant callback:** in `onChange`, verify `snapshot()` already sees new text/selection/revision; invoke the same controller's `replaceSelection`/`undo`/`copy` and expect `LifecycleReentry`; enqueue `app.post` for a later safe edit. `onSubmit` and `onIssue` get the same guard. An outside callback error must still clean session.
4. **Shared source:** mount two independent editors over one `Observable<String>`; move the first caret, edit the second, process the normal safe boundary, then assert the first advances its own text revision, clears history, clamps only its own selection and does not import the second caret. Repeat with equal-value `set` and `notify`.
5. **Actual conditional write race:** the worker gate in `fixtures/handshake.mjs` self-tests READY/GO/WRITE/COMMIT. Attach UI and background actors through a genuine production operation; record a trace showing UI read of source version *v*, actual background `Observable.set` reaching *v+1* before editor conditional write, and a rejected editor write. Require `ConcurrentValueChanged` once, no stale overwrite/undo/onChange. If public scheduling cannot expose that exact interval, leave this case blocked and inspect the internal version helper in TASK120. No sleep, fake Observable, or public test setter substitutes for the proof.
6. **Clipboard:** headless `copy` and `cut` use actual `Application.copyLocalText` result and retain selected data on Unsupported. A real TTY explicitly configured Direct may return SentUnconfirmed after complete OSC52 write; record emitted bytes/status and retain text/selection/history with one CutUnconfirmed. Copy returns no issue for SentUnconfirmed. There is no production Applied adapter: `fixtures/oracle.py` gives pure value policy only. For future Applied support, use the delivered adapter and assert same mount/session/source/text/selection revisions before deletion. For app-delayed consumption, capture snapshot, post later, then use `replaceSelection("", ifUnchanged: Some(saved))` only after authentic Applied; stale/move-away-back must return false and caller reports the late result.
7. **Actual PTY:** drive `Application.run` through a PTY after 117, 152 and interaction focus/modal are fixed. Send the seven-bit bracketed paste frame in split writes with LF, ESC and `0x03` payload; assert one editor transaction and one undo. Move focus A→B after paste begin; A retains ownership while valid. Unmount A or open isolating modal before end; assert no edit and one PasteTargetUnavailable. EOF mid-paste yields no edit and IncompletePaste before cleanup. Capture raw terminal bytes and exit codes. Do not equate a single PTY's TERM variants with distinct host acceptance.
8. **Frame and default action:** test Theme roles TextInput/TextArea and selected/explicit style precedence with exact `Frame.cellAt`; width-two `A中B` must never show half `中`, and zero width hides caret while retaining data. Use `NodeRef.viewportSnapshot()` for the only offset owner. On nested ScrollView, PageDown in TextArea consumes one target default and causes no ancestor scroll. Earlier `preventDefault` blocks Enter/edit; `stopPropagation` alone does not. Tab/Escape remain framework defaults.

`tests/editing/src/` currently implements the executable subset of these recipes and hand-written state/Frame/notification assertions. Missing upstream paths stay pending rather than being replaced by local fake classes or an Applied backend.
