# 产品说明

cjtui 的目标是让应用使用组件块、属性链、仓颉状态和回调构造终端界面，不要求应用手工刷新或发送 ANSI。

当前状态：planned。新框架、示例和基准尚未实现，尚无可供安装的发行版。仓库名为 terminal.ui，CJPM 模块名统一为 cjtui；产品从需求和公开契约开始开发。

计划交付：主库、最小应用与组合应用示例、可重复执行的基准项目，以及安装、构造语法、API、主题、终端能力和已知限制说明。相关内容验证后再补充，不提供尚不能运行的安装或调用命令。

依赖：ansies 1.3.113、unicode 0.1.0（中心仓）；兼容性待验证。候选构建基线为仓颉 SDK 1.2.0，当前无产品构建通过声明。
