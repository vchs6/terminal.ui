# 运行统计

`Application.stats()` 返回当时的只读 `RuntimeStats` 快照。`arranges` 统计实际执行节点尺寸、位置与裁剪分配的次数；完整 `render` 参考计算也计入。主题候选的无输出预检不计入。

`cellWrites` 统计应用生成目标、挂载组件的完整 `render` 参考帧及返回的 `snapshot` 副本时，Frame 目标 Cell 槽实际初始化、清理、宽字符伙伴修复和覆盖写入的次数，同一槽重复写入重复计数。`frameAllocatedCells` 统计这些操作中成功分配的 Cell 存储槽，包括目标、层、副本和合成所需临时 Cell 数组；它不是字节数，也不包含字符串、节点、引用目录或其他堆分配。临时源数组的初始化不算目标槽写入；终端输出编码阶段的投影行也不属于目标生成统计。

计数属于当前应用会话并随工作累计；结束后保留最后快照，重新启动从零开始。调用者随后修改或复制已返回的 Frame，以及独立创建和操作 Frame，不计入应用。其他八项的含义不变；这些计数不承诺局部布局或绘制性能。
