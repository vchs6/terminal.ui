# 迁移下载总目录独立验证

固定 Git 提交 `3f2e9f7e50349afd828ab61cf896afd460b65b62` 中有 27 份迁移压缩包，共 1,323,382,919 字节，约 1.23 GiB。卷序为 01–05、06a–06l、06m1–06m3、06n–06t。压缩包及 27 份独立校验文件均为普通 Git blob。

从固定提交逐卷流式读取实际 Git blob，并独立复算原始文件 SHA-256、Git blob SHA-1 和字节数。27 卷逐项匹配对应校验文件及 Git 树记录。工作区的逐卷校验文件与固定提交逐字节一致。

中文下载总页、JSON 索引、纯文本 URL 列表、总校验清单及下载脚本的归档条目一一对应。所有 27 个 URL 均固定到同一提交。JSON 清单中的文件名、字节数、SHA-256 及 Git blob 均等于独立实测。总页中每卷的十进制 MB 显示按实测大小舍入。

下载器通过 `sh -n`。在主机 RAM 的临时目录，用离线替身运行脚本，验证自定义和默认目录两种正常流程。每次只调用一次带断点续传参数的 `wget` 交付全部 27 个固定 URL，再调用一次 `sha256sum --check` 核对全部 27 条真实清单记录。模拟下载失败时脚本返回非零且跳过校验。模拟最后一卷校验失败时脚本返回非零。测试输出只有归档占位文件。
