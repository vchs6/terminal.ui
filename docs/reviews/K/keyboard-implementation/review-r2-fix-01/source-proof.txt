For an invalid UTF8 continuation in a previously over-budget Alt candidate, the decoder clears only utfRemaining, retains drained, transitions to its existing nonstring sequence state, and reconsumes the current byte. That state's existing drain consumes parameter/intermediate bytes through a final byte and uses the same top-level ESC, raw03 and true scalar-boundary C1 cancellation rules as before. For a non-drained Alt candidate, InvalidUtf8 remains reported at utfStart, state returns to normal, and the independent byte is retried. This is source reasoning; executed cases and outputs are separately recorded.
