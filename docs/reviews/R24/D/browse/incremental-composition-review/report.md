## D-140-001 — P1: a partial repaint can resurrect a caret behind an unchanged opaque layer

Primary location: `src/layout.cj:593–625`; supporting paths: `src/paint_context.cj:73–81`, `src/frame.cj:75–99,154–162,326–345`, `src/runtime_session.cj:1632–1645`.

Reproduction conditions: a focused Canvas covers multiple rows and declares a caret on row Y. A passive opaque overlay covers that cell while keeping the Canvas focused. After a complete target, caret visibility is false. Change another node/layer whose bounds occupy a different row Z inside the same Canvas, without changing the Canvas, focus, geometry, or opaque covering layer on Y. The unchanged Canvas intersects Z and executes its draw callback once with its original context, so it declares the same caret on Y again.

`produce` clears pendingCaret, and only a previously *visible* request can survive in lastCaret; the covered request was discarded. On the new pass the Canvas recreates pendingCaret on Y, but the Frame write filter excludes Y and the clean covering layer either does not paint or transfers only Z. Therefore neither target nor layer observes an opaque write at the newly declared caret coordinate. `finishCaret` clears only an observed request with caretCovered=true. `produce` then checks only bounds and continuation and publishes the recreated request as visible, although the complete target still contains the opaque covering cell. The failure also applies to same-character StyledSpace coverage and shadows whose row remains clean.

A concrete public layout is a three-row focused Canvas next to three one-row siblings, with an unchanged passive cover on its middle-row caret; changing the first/last-row sibling reproduces the missing coverage check. A separate short overlay on Z can supply the same unrelated damage. Complete M1/M2 Cell equality will still pass, because global render intentionally does not update Application caretSnapshot.

This violates adopted M004 and terminal-output spec “Caret-only changes”: cached requests must respect actual opaque ownership, including identical StyledSpace. It also exposes the quality defect: frame-local observations of writes in this pass are treated as sufficient coverage evidence for a request outside this pass's damaged rows. Retain valid logical request/coverage state for unchanged rows or obtain equivalent complete coverage proof before publishing such a request, while preserving original context and at-most-once draw. Do not fix this by treating the final Cell's character/style as ownership or globally forcing full repaint. A focused independent regression must assert the logical caret, full cells, draw counts and transparent-hole control.
