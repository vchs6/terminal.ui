## 已核对的设计维度

| 维度 | 审核判断 |
|---|---|
| 字符终端边界 | 行列、字符簇、键盘为核心；未引入GUI/字体/像素后端或运行时JS/TS。标题/图片图标隔离为可选宿主能力。 |
| 节点及描述 | 业务对象、可重算描述和持久节点分离；稳定身份保留焦点/编辑/订阅，卸载释放引用；主题切换不重建业务状态。 |
| 混合子序列 | 同一容器子序列、按位置操作、统一生命周期；不按数据通知清空全部子项或推断数据保留。无效锚点/跨父/重入等明确归TASK-004冻结，032集成。 |
| 通知与调度 | 响应式/显式定向通知合批进入UI域；后台不能无同步改树；普通变量初值不冒充依赖跟踪。 |
| M1/M2 | 主规格和design要求M2等价且减少内部工作，并允许resize全帧失效；旧架构残留见IR-003。 |
| 实际尺寸 | 小于最小值仍按实际空间、不自动隐藏，固定小控制台与resize一致；通用滚动任务遗漏见IR-002。 |
| 键盘/编辑 | 焦点→父→当前输入域应用处理器；模态未处理也不穿透；单/多行Enter、字符簇编辑、括号粘贴与协议限制有边界。 |
| 系统剪贴板 | SSH目标为使用者本地；接收终端粘贴，不发读取查询、不用远程xclip冒充；applied与sent_unconfirmed分开，未确认剪切默认保留选区。 |
| 标题/真实图片图标 | OSC1名称和界面内图片均不冒充宿主位图；没有适配可unknown/unsupported；恢复仅在原值保存及通道可用时承诺。 |
| 主题 | 分类单文件TOML、变量/命名样式、显式优先、状态优先、复位、原子应用、请求顺序及坏配置保旧有说明；无默认监听。 |
| 四主题与基础组件 | 需求和展示场景覆盖全部已列组件/状态；候选任务未冒充已实现。集成闭合需IR-001修订。 |
| 决策/假设 | TOML、状态覆盖顺序和保守剪切策略标明工程细化；语法精确签名、终端矩阵、联合库产品消费、许可仍待后续，不伪称用户逐项指定。 |
| 主规格/增量 | 7项delta的Requirement文本及场景与主规格逐条匹配；任务/长期旧条款仍有上述缺陷。 |

U1–U5的构造模型可用于后续冻结，未提供产品可编译入口是当前阶段的明确边界；不能据此判框架不可用。U6–U10增加的设计场景覆盖混合操作、通知、编辑/resize、主题和宿主能力。实际便利性、视觉交互和性能尚无产品运行证据，本报告不把设计认可当运行结论。
