# 准备可独立接续的开发检出

## Why

当前 main 检出包含前次工作区迁移卷和历史验收原件。新开发者只需取得项目源码、可执行测试、当前接续材料和锁定的外部依赖，即可从当前 Linux 进度恢复工作。

## What Changes

- 用普通向前提交移除当前树的历史迁移卷、原始审查堆积和重复接续记录。保留固定旧提交以查询历史。
- 将交互 C 准入和颜色 resize oracle 实际读取的原始输入放入测试夹具，保留输入摘要和来源。控件与主题测试继承本地开发环境。
- 提供从部分克隆、官方 SDK 和 stdx、中心仓依赖到构建、检查和当前任务的本地开发路径。
- 在项目源码树保存 C008 工作输入和 TASK-023 的已知红测，记录各自的验证边界。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无产品或流程规格行为变更。沿用 development-workflow 的现有追踪、验证和准入要求。

## Impact

影响仓库检出内容、文档入口和测试数据定位。仓颉产品源码、构建契约、公开 API、既有 Linux 任务状态和发布授权沿用现有记录。
