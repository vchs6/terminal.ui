# Spec Delta

## MODIFIED Requirements

### Requirement: 状态与生命周期

框架 SHALL 同时接收响应式变化和显式定向通知，自动调度内容、状态、样式、布局和结构更新，合并批量变更；稳定 key 管理身份，卸载释放订阅，后台更新经 UI 调度入口。

#### Scenario: 文本缩短与重排

- **WHEN** 列表重排且绑定文本变短
- **THEN** 节点按稳定身份保留局部状态，残留文本被清除，卸载节点不再接收更新。

### Requirement: 布局与装饰区域

框架 SHALL 区分布局、绘制和交互区域，支持横纵嵌套及固定/内容自适应/比例分配，充分使用实际视口，定义弹性取整、空间不足和祖先裁剪；阴影默认只扩展绘制，不扩大命中区域。

#### Scenario: 窄屏与阴影裁剪

- **WHEN** 嵌套容器缩小且子组件带边框和阴影
- **THEN** 最小尺寸无法满足时按实际可用尺寸布局，不拒绝运行、不自行隐藏，按公开裁剪/滚动规则显示，不产生半个宽字符，阴影不抢占点击区域。

## ADDED Requirements

### Requirement: 实际尺寸与滚动

框架 SHALL 以终端实际行列为根布局边界，响应尺寸变化；内容默认纵向滚动，表格允许横向滚动，单行输入内部视口保持光标可见；组件显隐由应用显式确定。

#### Scenario: 固定小控制台

- **WHEN** 实际80×24且应用最小尺寸100×30
- **THEN** 仍以80×24布局，不强制放大或维持超大最小画布；内容可按组件规则访问。

#### Scenario: 缩放与可见性

- **WHEN** 窗口缩小再恢复
- **THEN** 重新分配可用空间，保留节点状态和有效焦点，不因空间变化自行隐藏分区。


### Requirement: 键盘事件与模态域

框架 SHALL 提供归一化键盘事件，支持预处理拦截、阻止默认行为及停止传播；事件从焦点组件沿父链到当前输入域应用处理器，模态时不触发下层快捷动作。

#### Scenario: 事件消费

- **WHEN** 焦点组件处理一个按键并停止传播
- **THEN** 父组件及应用处理器不重复执行业务动作。

#### Scenario: 模态未处理

- **WHEN** 模态窗口内没有组件处理某全局快捷键
- **THEN** 不得穿透执行下层应用快捷动作；关闭后恢复有效焦点。


### Requirement: Unicode 编辑与默认快捷操作

框架 SHALL 提供单行/多行输入、字符簇级光标与删除、选择、剪切复制粘贴、撤销重做的标准快捷操作，其他绑定由应用定义；单行 Enter 提交，多行 Enter 换行。

#### Scenario: 字符簇编辑

- **WHEN** 输入中文、组合字符、ZWJ或肤色emoji并移动删除选择
- **THEN** 按冻结字符簇策略操作，不拆开簇；终端字形限制明确说明。

#### Scenario: Enter与拦截

- **WHEN** 单行或多行收到未拦截Enter，或应用阻止默认行为
- **THEN** 分别提交或换行，被拦截则不执行默认；多行提交由应用定义。

#### Scenario: 粘贴与协议限制

- **WHEN** 接收括号粘贴或旧终端不可区分按键
- **THEN** 粘贴不逐字符执行快捷命令；按支持矩阵报告事件能力限制，不伪造KeyUp或修饰键。


### Requirement: 默认与受控交互状态

框架 SHALL 为焦点、选中、展开等通用状态提供默认管理及公开绑定控制；业务等待/错误由视图组件组合，组件状态变化自动参与样式和绘制失效。

#### Scenario: 受控状态

- **WHEN** 应用绑定组件选中状态
- **THEN** 以该受控值为权威，事件回调不与内部副本循环覆盖；卸载清理关联。
