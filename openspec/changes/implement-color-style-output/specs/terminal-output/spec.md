## ADDED Requirements

### Requirement: 自动终端能力适配

框架 SHALL 使正常应用声明完整颜色与文本属性，由设备渲染路径自动获取终端能力并执行确定性降级；不得要求程序员手动选择实际支持级别。高级可选覆盖不得成为默认路径。原始颜色与样式 SHALL 保留，能力未知时保守处理并可诊断来源，不把未知冒充支持成功。

#### Scenario: 相同应用跨能力宿主

- **WHEN** 未指定能力override的相同RGB/属性应用分别运行于已确认不同能力的实际终端
- **THEN** 渲染自动采用对应转换，应用源码不判断终端能力，逻辑Style保留原值。

#### Scenario: 信息不足或来源失败

- **WHEN** 终端信息缺失、查询不支持或不能验证能力
- **THEN** 框架按冻结保守策略继续基础界面并记录可诊断来源，不要求应用处理探测，不声称未确认能力已成功。
