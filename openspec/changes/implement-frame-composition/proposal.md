# 完整帧合成与快照原语

当前 Frame 只有不透明单元，缺少层合成、复制/清空/缩放与文件快照入口。本变更补齐 TASK-005/007 的帧层责任，并交付 TASK-010 的文件导出部分，为后续覆盖层和 M2 提供同一目标帧基础。

保留既有 Frame/Cell/Style/Unicode/ansies 路径，不引入第二缓冲或绘制内核；低层透明状态必须与有样式空格区分。精确接口与字符簇边缘策略见 design.md。应用覆盖层生命周期、富文本解析、状态调度不在本变更内，仍由总计划连续推进。TASK-010 的含实际可见层集成 AC 保持待验，不能以这里的写文件接口代替。

这是执行型实现，包含可逆接口细化：依据既有 REQ-004/005 和独立审计补齐具体签名。用户已授权全部 Linux 实施，无新增产品目标或发布动作。
